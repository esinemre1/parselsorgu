# Parsel Sorgu

Tarayıcıda çalışan parsel sorgulama arayüzü. Masaüstü EXE sürümündeki HTML/JavaScript arayüzünden web sürümüne uyarlanmıştır.

## Özellikler

- İl / ilçe / mahalle seçimi
- Ada / parsel sorgusu
- Leaflet harita üzerinde parsel geometrisi
- Google Hybrid ve OpenStreetMap taban haritaları
- Parsel alanı ve konum bilgisi
- DXF R12 dışa aktarma
- ITRF/GRS80 tabanlı 3° TM koordinat dönüşümü

## GitHub Pages

Repo `main` dalı kök dizininden GitHub Pages ile yayınlanabilir.

> Not: TKGM CBS API tarayıcıdan gelen isteklerde CORS kısıtı uygularsa statik GitHub Pages üzerinde sorgu doğrudan çalışmayabilir. Bu durumda aynı arayüz küçük bir backend/proxy ile kullanılabilir.
